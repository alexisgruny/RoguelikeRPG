# RoguelikeRPG 🎮

Un RPG roguelike au tour par tour développé en TypeScript. Chaque partie est unique grâce à la génération procédurale des ennemis, biomes et loots.

## ✨ Fonctionnalités
- ⚔️ Combats au tour par tour
- 🌍 Biomes générés aléatoirement
- 👾 Ennemis aléatoires
- 🎁 Système de loot aléatoire
- 💀 Roguelike — chaque mort repart de zéro

## 🧰 Stack
- **TypeScript**
- **Node.js**

## 📦 Installation
```bash
git clone https://github.com/alexisgruny/RoguelikeRPG.git
cd RoguelikeRPG
npm install
npm run dev
```
